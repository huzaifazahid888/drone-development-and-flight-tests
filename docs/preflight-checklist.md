# Preflight checklist

This is the checklist I want to use before each flight, mainly to avoid mixing the configuration from one drone with another.

- [ ] Check the correct drone and PX4 parameter file.
- [ ] Check the frame, arms, fasteners and propellers.
- [ ] Check motor order, rotation direction and propeller placement.
- [ ] Check battery condition and secure its mounting.
- [ ] Check the centre of gravity and flight-controller/GNSS mounting.
- [ ] Check RC link, telemetry, flight modes and failsafe settings.
- [ ] Wait for the required sensor and EKF2 health checks.
- [ ] Check the sight and RF link where fitted.
- [ ] Confirm the test area is safe and clear.
- [ ] Record the test purpose and confirm flight-data logging is enabled.

After the flight I will check battery behaviour, the ESC and motor temperatures and any warnings, then save the test video and relevant notes. All powered motor tests without propellers will be done with the aircraft secured.
