# Drone setups

This project started with a small drone. After learning the basic setup and making some flight tests, I moved to a mid-size quadcopter. The current drone is larger, with dimensions of about 736 mm × 615 mm.

I am keeping every drone in a separate folder because the motors, propellers, flight controller settings and flight results can be different.

- [01 - Small drone](01-small-drone/README.md)
- [02 - Mid-size drone](02-mid-size-drone/README.md)
- [03 - Large drone, 736 × 615 mm](03-large-drone/README.md)

I will add the actual hardware photos and specifications after checking which parts belong to each drone. The names for the photos and videos are already recorded in the media folders.
