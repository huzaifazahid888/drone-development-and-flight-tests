# Photos and flight videos

This folder is for the actual pictures and videos of the three drones. I will use the filenames already mentioned in the README so that the correct media appears with each build.

The photos are not added yet. The image and video names in the documents are reserved names, not fabricated media.

[Photo filenames](photos/README.md) · [Video filenames](videos/README.md)

For long flight videos I may add a compressed clip here and keep the full recording as a link or a GitHub Release. GitHub does not accept normal repository files larger than 100 MB.

Before public sharing I will check media for GPS metadata, visible locations and other private information. Raw ULog files may contain position data, so I will review them before uploading.
