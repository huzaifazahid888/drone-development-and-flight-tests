# PX4 flight logs

I use PX4 ULog files to check the behaviour of the drone after real flights. The raw logs can contain GPS position, the flight path and other system information.

I have not uploaded raw logs here. The `.gitignore` excludes `.ulg` and `.tlog` files by default. I will review any log before deciding whether it should be shared publicly.

The [flight-test records](../docs/flight-records/README.md) describe the measurements and findings without publishing original flight coordinates.
